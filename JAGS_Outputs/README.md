# JAGS outputs

The model scripts save their `*_coda.RData` and `*_jags.RData` files here.
The outputs of `model_7_1.r`, `model_7_2.r`, and `model_7_3.r` provide informative
priors for `model_8.r`, `model_9.r`, and `model_10.r`, respectively.
See the [main README](../README.md#run-the-analyses) for execution order.

Generated files here are ignored by Git. This README keeps the directory present
in a fresh checkout; `data_prep.r` also creates it if needed.
